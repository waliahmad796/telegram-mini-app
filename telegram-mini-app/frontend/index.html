🛠️ Development Mode
You're viewing this in a browser. To test the full Telegram Mini App features:
Option 1: Quick Testing with ngrok
1. Install ngrok: npm install -g ngrok
2. Start local server: python -m http.server 8000
3. Start ngrok: ngrok http 8000
4. Use the HTTPS URL with your Telegram bot
Option 2: Deploy to Production
1. Deploy this app to a hosting service (like Vercel)
2. Create a Telegram bot with @BotFather
3. Set the Mini App URL to your deployed URL
4. Open the app from your bot in Telegram
Check the browser console for mock Telegram API calls.
